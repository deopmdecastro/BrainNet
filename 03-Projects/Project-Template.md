# Modelo padrão de projeto

O modelo editável é [[../Templates/Project|Templates/Project]]. No Obsidian, inserir através do comando nativo Templates: Insert template. O diretório de modelos já está configurado.

Para projetos com vários entregáveis, criar uma pasta com Project-Brief, Requirements, Decision-Log e Testing-Plan; expandir apenas quando necessário. Estado e responsável ficam no frontmatter do briefing. Tarefas usam [[../Templates/Task|Task]] e decisões usam [[../Templates/Decision|Decision]].
