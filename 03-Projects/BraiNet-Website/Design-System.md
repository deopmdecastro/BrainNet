# Sistema visual proposto

Direção: editorial, técnica e clara. Base clara com texto escuro; destaque azul profundo e sinalização verde limitada a estados de sucesso. Confirmar identidade existente antes de produzir assets.

| Token | Proposta |
| --- | --- |
| Fundo | `#F5F7FA` |
| Texto principal | `#102334` |
| Destaque | `#1646B5` |
| Superfície | `#FFFFFF` |
| Tipografia | System UI sem downloads iniciais; alternativa a avaliar com a marca |
| Espaçamento | Escala 4, 8, 12, 16, 24, 32, 48, 64 px |
| Grelha | 4 colunas mobile; 12 desktop; largura de leitura limitada |

Componentes iniciais: navegação, botão, link, cartão de serviço, campo, erro, recibo de submissão e rodapé. Definir normal/hover/foco/disabled/loading/success/error. Estados não dependem apenas de cor. Respeitar preferência de movimento reduzido; animação apenas se ajudar uma tarefa.

A combinação final de cores, tamanhos e estados exige medição de contraste e testes de teclado. Não existe interface implementada nesta fase.
